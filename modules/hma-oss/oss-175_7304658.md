Prepare for new version (#164) with New Crowdin updates (#160)

We've implemented so many things in this release, but here are some highlights:

- Add support for Android 17 QPR3 Beta 1 and later (not guaranteed for Beta 4 and above; we can't predict the future)
- Make system apps visible in the target app list when enabled
- Remove the WebView protection
- Try to fix app-list-hiding detection in a better way (it may still be detected on some OEM ROMs because of aggressive inlining)
- Add hooks for usage stats-based detections
- Switch to AGP 9.x
- Refactor the about screen a bit
- Add new apps to the presets
- Add support for the external managers (it listens for changes in config.json)
- Remove some unnecessary hooks
- Refactor the hooking API a bit

Also thanks for translators, they did an amazing job to fix existing translations in this release.
